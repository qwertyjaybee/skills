# Architecture Decision Records (ADRs)

Architecture Decision Records document significant architectural decisions, alternatives evaluated, trade-offs, and outcomes.

## Naming Convention
Files in this directory follow the pattern:
`ADR-XXX - Title.md` (e.g. `ADR-001 - Obsidian Knowledge Vault Integration.md`)

Use [[Templates/Template - Architecture Decision Record|ADR Template]] when creating a new record.
